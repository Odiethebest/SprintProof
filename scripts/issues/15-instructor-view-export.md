## User story
As a TA grading a dozen teams, I want a read-only sprint summary with one-click Markdown export, so I can see the whole story without digging through Slack.

## Acceptance criteria
- [ ] `/review/[teamId]` for `INSTRUCTOR`: dashboard, standups by person, retro items, action items and peer feedback
- [ ] No edit controls are rendered on the page
- [ ] `ExportButton` downloads `sprint-N-summary.md` with sprint dates, per-member counts and status, standups by person, retro items and action items
- [ ] Instructor export includes peer feedback; `LEAD` export does not
- [ ] Markdown is generated by a pure function in `src/lib/export/` with unit tests asserting the sections and values
- [ ] Export format matches the files in `docs/sprints/`

**Estimate:** 5 points
**PRD:** US-10
**Depends on:** #12, #14
